# Contributing to Praxis

Praxis is still being prepared for its first public source release. The repository is currently a placeholder, so substantial code contributions are not yet being accepted.

Once the source is published:

- Open an issue or discussion before starting a large change.
- Keep pull requests focused and explain the behavior being changed.
- Include tests or reproducible verification where practical.
- Do not commit generated binaries, build output, credentials, logs, dumps, private server data, or unrelated reverse-engineering reference repositories.
- Do not submit code or assets unless you have the right to redistribute them.
- Preserve all existing copyright, attribution, and third-party license notices.
