## Scope

This is a UI-only refinement. The 19 utility modules, native hooks, map,
inventory, LHolo bridge and offline-only resource-pack native reload policy
are unchanged. No config schema migration or additional event listeners.

- Sidebar: grouped Main / Tools / Settings, shorter Japanese labels, slimmer
  width, low-contrast buttons, unobtrusive accent selection rail. Page IDs are
  unchanged.
- Palette: calmer neutral surfaces, subtle borders and headers, accent on
  deliberate interactions rather than every button.
- Modules: ON counter, denser cards, descriptions remain available on hover,
  module help moved into a collapsed section. Toggle/favorite/setting IDs and
  effects stay the same.
- HUD: five primary enable switches in a quick-control area. Existing six
  named HUD sections and Japanese/English search aliases are retained;
  per-HUD display/position/details are collapsed by default.
- Block comparison: short block names; current target, reference and result
  on simple rows. Exact owned client state/labels remain in memory for
  comparison; no extra world scan or state change. Full target label can be
  inspected on hover.
- Compatibility: concise loaded/not-loaded Lamium readout plus existing
  Praxis-only overlap toggle, with no mutation of Lamium.

- In-game visuals are NOT_RUN until the user launches Minecraft.

## Installation and rollback

Build is staged in a dedicated package outside LeviLauncher.
Installation is only permitted while Minecraft.Windows.exe is absent.
The package's installer backs up the previous DLL/PDB and configuration,
replaces only the matching DLL/PDB and verifies SHA256. Rollback restores
the previous DLL/PDB without overwriting or removing current config.
Neither the LHolo nor Minecraft world files are modified.
The resource-pack hot reload remains gated to the exact disposable
offline R17 test clone, not ordinary production worlds or servers.
