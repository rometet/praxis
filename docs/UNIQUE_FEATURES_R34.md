# Praxis 独自機能 R34 ローカル検証

対象: Minecraft Bedrock Windows 1.26.51.01 / LeviLamina Client 26.51.5 / LHolo の互換版。
ベースラインは rometet/praxis の R33 (d881ae4)。既存のリソースパック再読み込みの厳格なオフライン専用ガードは変更しない。

## 追加内容

### 1. ブロック状態比較
- Praxis F10 → 「ブロック状態比較」
- 初回は「照準ブロックの状態取得を有効化」をクリックする
- F10 を閉じ、読み込み済みチャンクのブロックへ照準を合わせる
- F10 を開き、ブロック名と状態が表示されたら「この状態を基準にピン留め」
- F10 を閉じ、別の同種ブロックに照準を合わせてから再び F10 を開く
- 向き/状態などが一致すれば「一致」、異なれば「異なる」。座標は比較から除外する
- 基準と現在対象の情報をクリップボードにコピーできる
- 対象がない・2.5秒より古い・未読み込み・他ワールドでは情報を拒否する
- ブロックを変更することも、ワールド全体を走査することもない
- 基準はセッションメモリ上だけにあり、ワールドを移動すると破棄される

### 2. Lamium 共存診断
- Praxis F10 → 「Lamium共存」
- Lamium.dll と LHolo.dll のロード有無を表示
- Lamium と重複する可能性がある Praxis の有効機能だけを一覧化
- Lamium を検出できた場合、明示的に選択する「上記のPraxis機能だけOFF」で一括無効化
- Lamium 側の設定やファイルを編集しない
- Lamium の各機能が有効かどうかまでは検出しない
- リソースパック、RedstoneOverlay、WeatherChanger などの固有機能は無効化対象に含めない
- キー競合には追加の表示案内のみ。Lamium 側のキー割当は変更しない

## 検証内容
- PraxisCompanion DLL release build PASS
- 新規ポリシー 135 checks PASS
- 既存 Inspector 56 checks PASS
- ImGui 実描画/ページ・日本語表示 13,831,012 checks PASS / 6,548 frames
- 実機 Minecraft 内での操作は NOT_RUN。ユーザー実機確認待ち。

## 実機確認（バックアップ済みのテスト用ワールドを使用）

1. Minecraft を完全に終了する（LeviLauncher は起動中でも可）。
2. 配布フォルダの Install.cmd をダブルクリック。成功表示を確認する。
3. LeviLauncher の 1.26.51.01 を起動して、F10 の新しい2ページを確認する。
4. ブロック状態比較：オブザーバーを同じ方向と逆方向に設置し、状態比較がそれぞれ一致/異なるになることを確認する。
5. Lamium が入っていなければ「未検出」は正常。導入している場合は認識されるか確認する。一括OFFの動作を確認する場合、Praxis機能をひとつ ON にしてから操作する。
6. LHolo メニューと F10 の開閉、プレイヤーの表示を確認する。
7. 問題があれば Minecraft を終了し、Rollback.cmd で以前の DLL/PDB に戻す。

注意：このパッケージで R33 のワールド内リソパ操作の対応範囲は広がらない。実際のサーバー・本番ワールドで R33 の実験的な操作を試さない。

### パッケージの安全性
- インストーラーは Minecraft 起動中に上書きしない。
- 既存の DLL/PDB と構成・manifest をバックアップする。
- 既存の設定ファイルはインストール・ロールバックともに削除しない。
- .cmd は Windows 標準 PowerShell を呼び出すだけで、外部ダウンロードや自動再起動はしない。
- GitHub への公開・リリースは実機確認後に判断する。
