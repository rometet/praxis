# LHolo coexistence

LHolo is the optional schematic/projection/placement mod. PraxisCompanion is the standalone utility mod. When LHolo is absent, Companion uses its own graphics/input host based on the old Praxis D3DHook. When LHolo is present with a compatible bridge, Companion installs no second graphics/WndProc hook.

LeviLamina 26.51.5 exposes `AfterUIRenderEvent`, `KeyInputEvent` and `MouseInputEvent`. The first UI event selects a backend. Without LHolo, Companion creates its own ImGui context and DXGI/Win32 hooks, with typed `IClientInstance::releaseMouse/grabMouse` and LL input guards. The actual `LHolo.dll` from [LHolo PR #12](https://github.com/rometet/LHolo/pull/12) optionally exports a versioned bridge from its existing ImGui frame. Companion finds the enabled LHolo NativeMod through LeviLamina's registry. Registration checks `IMGUI_VERSION_NUM` and the sizes of `ImGuiIO`, `ImGuiStyle`, and `ImDrawVert`. With that bridge, LHolo owns cursor, ClipCursor, raw game input handoff and all DXGI hooks. Without a compatible bridge while LHolo is present, the GUI is blocked and native utilities continue.

LHolo's default menu key is Insert. Companion uses F10 through the bridge. LHolo's configurable shortcuts are evaluated first; a user assigning F10 to LHolo keeps LHolo priority. While LHolo's menu is visible, F10 does not open Praxis. While Praxis is visible, pressing LHolo's menu key closes Praxis and opens LHolo in the same input owner. Escape/F10 closes Praxis through LHolo's existing cursor handoff. The bridge also exports LHolo's current input-owner state so Companion's Zoom does not engage or capture wheel movement while either menu owns input. The same bridge stops callbacks before either DLL unloads. The implementation adds no second Present or WndProc hook.

Static audit: in bridge mode no graphics hook targets overlap LHolo; in standalone mode LHolo is absent. Runtime tests remain mandatory for F11, resize, Alt+Tab, cursor visibility, held WASD/button release, wheel ownership, projection visibility, leave/rejoin and shutdown. See [RUNTIME_TEST_PLAN.md](RUNTIME_TEST_PLAN.md).
