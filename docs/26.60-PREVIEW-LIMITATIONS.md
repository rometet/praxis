# 26.60 preview limitations 窶・v0.1.5-rc.1

> **Historical v0.1.5-rc.1 preview report.** Its negative results below refer to that earlier build. They do not describe the current **v0.1.7-rc.1**, in which the user verified TimeChanger, WeatherChanger, NoRender Weather, in-world resource-pack texture refresh, FreeCamera, HandRestock and FlexiblePlacement. See the root README and latest Release for current limitations.

This is an experimental Windows x64 port to Minecraft **1.26.60.05**, LeviLamina Client **26.60.0**.

**Verified:** candidate build and link; the tested Minecraft version can load Praxis and initialize its F10 ImGui GUI.

**Not fully verified:** all-module 26.51 parity, BDS/multiplayer operation, HUD and overlay visual quality, FreeCamera, TimeChanger/WeatherChanger, inventory transactions, FlexiblePlacement on every server, and long-session stability.

**Placement:** only FlexibleBlockPlacement remains exposed. AccurateBlockPlacement and FastBlockPlacement are hidden and runtime-disabled even if older profiles saved them enabled. FastRightClick's advanced block-placement path is disabled while ordinary item-use remains.

**World resource-pack switch/reload:** DOES NOT WORK. In a 2026-11-05 local-world test, the Global stack changed 3竊・ but Minecraft did not reload textures. Logs reported `engine_restack pending=1 attempts=225 native_started=0`. The GUI's in-world Apply/Reload buttons are disabled; no texture-refresh success is claimed. [API request #288](https://github.com/LiteLDev/mcapi-requests/issues/288). Do not use experimental live pack switching with valuable world data.

**LHolo:** separately installed LHolo with flexible-placement ABI v2 is needed for FlexiblePlacement transformations; LHolo is not included and was absent from the last tested session.

**Weather:** sunny startup verifier reported `available=0` during one tested session; user-visible sunny behavior is not proven.

**Native unload:** reloading/unloading Praxis while Minecraft runs is unsupported. Restart Minecraft after updating.
