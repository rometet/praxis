# Praxis Client

Praxis Client is a Minecraft Bedrock Edition client-side project. The first public source release is currently being prepared.

**Praxis Client is an unofficial third-party project and is not affiliated with, endorsed by, or approved by Mojang Studios or Microsoft.**

## Current public-release status

- Minecraft target: `1.21.132.1`
- Public source repository: this repository
- Public source release: pending
- Public binary release: none published from this repository yet

The first public source snapshot will be imported from the audited current tree without importing the private development history.

## Binary and source correspondence

Every public Praxis Client binary release must identify the exact public source that corresponds to that binary.

Each public release must provide:

- the source repository URL: `https://github.com/rometet/praxis`
- an immutable source tag
- the exact source commit SHA
- the Minecraft target version
- the SHA-256 of the released binary

The README distributed inside each binary package must repeat the source repository URL and the corresponding tag and commit SHA.

See [`RELEASE_POLICY.md`](RELEASE_POLICY.md) for the publication rules.
