# Security Policy

## Release and support status

Praxis Client has public releases. Refer to [GitHub Releases](https://github.com/rometet/praxis/releases) and [README.md](README.md) for the latest published build and its exact Minecraft / LeviLamina compatibility.

Current development releases are experimental; **no long-term security support or guaranteed backports are promised**. Older tags remain available for source correspondence, but their presence does not imply they are secure or compatible with newer Minecraft versions.

## Reporting a vulnerability

**Do not disclose exploitation details, credentials, private server information, or other sensitive material in a public issue.**

Use GitHub's private vulnerability reporting feature if the repository offers it. Otherwise, open a public issue requesting a private reporting channel **without sensitive technical details**.

When reporting privately, include the affected version or commit, the impact, steps to reproduce, the platform and dependency versions, and any known mitigation. Avoid attaching private world files, personal information, tokens, or crash dumps containing secrets unless a secure channel has been established.
