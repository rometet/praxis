# Bundled UI fonts

Praxis Client embeds these fonts in the DLL as unmodified resources.

| UI option | Bundled file | Official source | License |
|---|---|---|---|
| Corporate Logo | `Corporate-Logo-Bold-ver3.otf` | User-provided original archive | SIL Open Font License 1.1; see the bundled Japanese notice |
| Noto Sans JP | `NotoSansJP-wght.ttf` | `google/fonts/ofl/notosansjp` | SIL Open Font License 1.1 |
| Inter | `Inter-opsz-wght.ttf` | `google/fonts/ofl/inter` | SIL Open Font License 1.1 |
| IBM Plex Sans | `IBMPlexSans-Regular.ttf` | `IBM/plex` | SIL Open Font License 1.1 |

The corresponding license texts are stored beside the font files as
`LICENSE-Noto-Sans-JP.txt`, `LICENSE-Inter.txt`, and
`LICENSE-IBM-Plex.txt`. The original Corporate Logo license and usage notice
are also retained in this directory.
